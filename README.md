# Site Portfolio Trainer - ArturBet

Адаптивный сайт-портфолио спортивного тренера с полной поддержкой мобильных устройств и GitHub Pages.

## 🎯 Функциональность

✅ **Отзывчивый дизайн** - Работает идеально на компьютере, планшете и телефоне
✅ **Героесекция** - Привлекательное представление тренера с фотографиями
✅ **Галерея упражнений** - Примеры упражнений с инструкциями по технике
✅ **Программа тренировки** - Структурированное описание занятия со временем
✅ **Демо-видео** - Место для встроенного видео с демонстрацией
✅ **Преимущества** - 6 карточек с основными преимуществами
✅ **Контактная форма** - Форма для записи на занятия
✅ **Мобильное меню** - Удобная навигация на мобильных устройствах

## 📱 Адаптивность

- **Desktop** (1024px+) - Полный многоколончный макет
- **Tablet** (768px - 1024px) - Оптимизированная сетка
- **Mobile** (480px - 768px) - Одноколончный макет
- **Small Mobile** (< 480px) - Компактный дизайн для маленьких экранов

## 🚀 Быстрый старт

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/your-username/ArturBet.git
   cd ArturBet
   ```

2. **Откройте локально:**
   - Просто откройте `index.html` в браузере
   - Или используйте Live Server в VS Code

3. **Разместите на GitHub Pages:**
   - Загрузите файлы на GitHub
   - Перейдите в Settings > Pages
   - Выберите основную ветку как источник
   - Ваш сайт будет доступен по адресу: `https://your-username.github.io/ArturBet`

## 🔧 Кастомизация

### Изменить название школы:
Откройте `index.html` и найдите:
```html
<div class="logo">💪 ArturBet</div>
```

### Изменить контактную информацию:
Найдите секцию `#contacts` и обновите:
```html
<a href="tel:+71234567890">+7 (123) 456-78-90</a>
```

### Добавить видео YouTube:
Замените `.video-placeholder` на:
```html
<iframe width="100%" height="300" src="https://www.youtube.com/embed/VIDEO_ID" 
    frameborder="0" allowfullscreen></iframe>
```

### Изменить цветовую схему:
В `styles.css` найдите переменные цветов:
```css
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
```

## 📸 Оптимизация изображений

Для лучшей производительности:
1. Сожимайте изображения перед загрузкой (TinyPNG, ImageOptim)
2. Используйте webp формат для новых изображений
3. Размер фото должен быть не более 500KB каждое

## 🚢 Развертывание

### GitHub Pages
1. Создайте публичный репозиторий `username.github.io` или `ArturBet`
2. Загрузите все файлы
3. Включите GitHub Pages в Settings
4. Сайт будет доступен через несколько минут

### Других хостинг-сервисов
- **Netlify**: Просто загрузите папку (бесплатно)
- **Vercel**: Синхронизация с GitHub (бесплатно)
- **Firebase Hosting**: Google сервис (с бесплатным уровнем)
